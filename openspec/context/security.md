# Безопасность и данные

- **NDA.** Внутренний код и данные банка в репозиторий и во внешние LLM не попадают. Примеры — синтетические (`agent/examples/`) или открытые наборы.
- **Секреты.** Ключи LLM и GitLab — только в `agent/.env` (не в git, не в Docker-образе, не в архиве сдачи). Шаблон — `agent/.env.example`. В образ `.env` не копируется: `.dockerignore` — белый список.
- **Перед LLM** маскируются значения секретов, Bearer-токены и номера карт (`rules.mask_for_llm`). Новые виды чувствительных данных — добавлять туда же с тестом.
- **ПДн в данных.** Колонки с никами авторов и ревьюеров удаляются при подготовке данных; в тексте замечаний `@ник` → `@user`, `/home/<ник>` → `/home/user`. Ники внутри кода OSS (копирайты, пути) остаются.
- **Человек в контуре.** Публикация — только CLI `--post` с подтверждением каждого замечания и всей пачки; без терминала ничего не публикуется. Approve и merge агент не делает ни в каком режиме. API только возвращает черновик.
- **Ответ модели недоверенный:** валидируется до попадания в черновик; у модели нет инструментов с побочными эффектами (prompt injection из diff не может вызвать действий).
