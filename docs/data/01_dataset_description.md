# Описание набора данных

## Источник

- **Набор:** [ronantakizawa/github-codereview](https://huggingface.co/datasets/ronantakizawa/github-codereview) (Hugging Face).
- **Что это:** inline-комментарии людей к pull request'ам из популярных open-source репозиториев с permissive-лицензиями. Комментарии ботов исключены автором набора.
- **Как получен:** `uv run python data/fetch_raw.py` — скачивает сплиты test и validation, оставляет только строки с `language = Python`, маскирует ключи AWS из чужого кода (`<AWS_ACCESS_KEY>`, `<AWS_SECRET_KEY>`, нашлись в 4 строках) и сохраняет в `data/raw/github_codereview_python.csv`. Повторный запуск файл не перезаписывает. Сплит train не берётся: модель не обучается, а test и validation дают ~5 000 Python-строк — этого достаточно для анализа и eval.
- **Лицензия и дата:** набор собран автором из репозиториев с permissive-лицензиями (MIT, Apache-2.0, BSD); лицензия самого набора на Hugging Face — `other`. Скачан 14.11.2026.
- **Анализ:** `notebooks/data_analysis.ipynb`.

## Признаки

| Колонка | Тип | Что это |
|---|---|---|
| `pr_title`, `pr_number` | str, int | заголовок и номер PR |
| `repo_name`, `repo_stars`, `repo_language` | str, int, str | репозиторий, звёзды, основной язык репозитория |
| `author_username`, `reviewer_username` | str | ники автора PR и ревьюера (персональные данные) |
| `before_code`, `after_code` | str | около 50 строк кода до и после правки |
| `diff_context` | str | hunk диффа, к которому оставлено замечание |
| `file_path` | str | путь к файлу |
| `reviewer_comment` | str | текст замечания; у кода без замечаний — `No issues found.` |
| `comment_type` | str | тип замечания: suggestion, question, bug, refactor, style, performance, security, nitpick, none |
| `comment_line` | int | строка замечания внутри фрагмента |
| `comment_length` | int | длина замечания в символах |
| `before_lines`, `after_lines` | int | число строк фрагмента до и после |
| `quality_score` | float | оценка качества замечания от автора набора, 0–1 |
| `is_negative` | bool | код прошёл ревью без замечаний |
| `language` | str | язык файла, после фильтра всегда Python |
| `split` | str | сплит набора (test / validation), добавлен при загрузке |

## Ограничения

- Код из open-source, а не банковский: банковских дефектов (секреты, ПДн в логах) в данных почти нет.
- Половина строк (49,4 %) — из 15 репозиториев; стиль этих проектов влияет на доли типов.
- Часть `comment_type` размечена эвристикой автора набора, доли типов приблизительные.
- Есть очень большие поля: diff до 3 735 токенов (здесь и далее токены оцениваются как символы / 3,5), замечание до 3 778 символов.
- В таблице есть ники авторов и ревьюеров — это персональные данные.

## Синтетические примеры

Кроме открытого набора в проекте есть два синтетических MR, написанных вручную: `agent/examples/mr_payments.diff` (перевод между счетами с типовыми дефектами: секрет в коде, SQL через f-строку, номер карты в логе, `verify=False`, голый `except`, HTTP без таймаута, UPDATE без транзакции) и `mr_clean.diff` (аккуратный код без замечаний). Они моделируют банковский код, которого нет в открытом наборе, и нужны для проверки правил безопасности и демонстрации; на метрики eval не влияют.
